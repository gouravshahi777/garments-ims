A SKU is flagged for reorder when X% or more of a received batch sells within Y days. This catches fast-moving items before they run out — even when current stock looks fine.

💾 Backup & Restore (FREE Cloud Storage via Google Drive)

Apna saara data ek file mein download karo. Phir us file ko apne Google Drive, email ko self-send, ya WhatsApp self-chat mein save kar do — kahi se bhi access kar sakte ho.

Backup karne ke 3 free tarike:
1️⃣ Google Drive: drive.google.com kholo → "+ New" → File upload → backup file daalo
2️⃣ Email: apne aap ko email karo, attachment mein backup file lagao
3️⃣ WhatsApp: apne aap ko message karo, file attach karo

Restore kaise karo: Naya computer ya phone? Bas backup file download karo, "Restore from Backup" button pe upload karo. Saara data wapas aa jayega.

💡 Tip: Hafte mein ek baar backup le lo (Sunday raat ko, 30 second ka kaam). Agar computer crash ho jaye, browser data clear ho jaye, ya phone change karo — restore button se sab wapas.
